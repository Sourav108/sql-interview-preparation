# Module 07: Window Functions

## Learning Objectives

By the end of this module, you will be able to:
- Explain the window function execution model and how it differs from GROUP BY.
- Write `ROW_NUMBER`, `RANK`, `DENSE_RANK` and choose between them for interview problems.
- Use `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE` for row-to-row comparisons.
- Apply window framing (`ROWS BETWEEN`, `RANGE BETWEEN`) for moving aggregates.
- Solve the canonical problems: Top-N per group, running totals, MoM delta, sessionization.
