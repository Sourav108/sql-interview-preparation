## Standard Problem Structure
Every problem adheres strictly to the following 11-part template:
1. **Problem Statement**
2. **Relational Schema DDL**
3. **Sample Seed Data**
4. **Expected Tabular Output**
5. **Progressive Hints (1–2)**
6. **Optimal Production Solution**
7. **Alternative Solution (Dialect-specific / window vs subquery)**
8. **Performance Analysis & EXPLAIN Plan Walkthrough**
9. **Time & Space Complexity** ($O(\text{Time}), O(\text{Space})$)
10. **Common Traps & Edge Cases**
11. **Interviewer Follow-Up Questions**
