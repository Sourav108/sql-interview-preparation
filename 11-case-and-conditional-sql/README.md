# Module 11: CASE and Conditional SQL

## Learning Objectives

By the end of this module, you will be able to:
- Write simple and searched CASE expressions for row-level classification.
- Apply conditional aggregation using CASE and FILTER to build pivot-style reports.
- Use COALESCE, NULLIF, GREATEST, and LEAST effectively.
- Perform explicit type casting with CAST and PostgreSQL `::` syntax.
