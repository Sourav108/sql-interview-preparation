## Master Interview Question Structure
Every question follows this standard format:
1. **Question**: The exact phrasing asked by senior technical interviewers.
2. **Short Answer**: A crisp 1-2 sentence executive summary.
3. **Deep Answer**: Technical mechanics, internal engine behavior, and trade-offs.
4. **SQL Example**: Minimal, executable demonstration code.
5. **Common Trap**: Mistakes that distinguish junior from senior engineers.
6. **Follow-Up Question**: Probing follow-up questions asked by interviewers.
