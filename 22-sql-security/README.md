# Module 22: SQL Security & Access Control

## Learning Objectives

By the end of this module, you will be able to:
- Explain the mechanics of **SQL Injection** and implement defense-in-depth using parameterized prepared statements.
- Configure PostgreSQL **Roles, Users, and Privileges** adhering strictly to the **Principle of Least Privilege**.
- Implement multi-tenant data isolation using **Row-Level Security (RLS)** policies.
- Configure audit logging and data encryption at rest and in transit.
