## Standard Mock Interview Transcript Structure
Each mock round includes:
1. **Interviewer Question & Business Context**
2. **Expected Senior Candidate Thinking Process**
3. **Candidate Spoken Answer & Code Draft**
4. **Interviewer Follow-Up Probes**
5. **Strong Senior Answer vs. Common Weak Junior Answer Comparison**
6. **Staff-Level Rubric & Evaluation Criteria**
