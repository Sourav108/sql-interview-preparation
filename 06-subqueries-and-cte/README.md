# Module 06: Subqueries and Common Table Expressions

## Learning Objectives

By the end of this module, you will be able to:
- Write scalar, multi-row, correlated, and derived-table subqueries.
- Choose correctly between `JOIN`, `EXISTS`, `IN`, and `NOT EXISTS`.
- Use CTEs (`WITH` clauses) to structure complex multi-step queries.
- Write recursive CTEs to traverse hierarchies and graphs.
- Understand PostgreSQL CTE materialization behavior.
