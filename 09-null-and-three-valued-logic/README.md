# Module 09: NULL and Three-Valued Logic

## Learning Objectives

By the end of this module, you will be able to:
- Explain exactly why `NULL = NULL` is `UNKNOWN`, not `TRUE`.
- Build correct truth tables for AND, OR, NOT with `UNKNOWN`.
- Identify and fix the `NOT IN (...) + NULL` silent failure.
- Apply `IS NULL`, `IS DISTINCT FROM`, `COALESCE`, and `NULLIF` correctly.
- Predict NULL behavior in aggregates, joins, sorting, and UNIQUE constraints.
