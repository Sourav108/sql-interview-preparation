# Module 13: Normalization & Pragmatic Denormalization

## Learning Objectives

By the end of this module, you will be able to:
- Identify and eliminate relational anomalies: **Insert**, **Update**, and **Delete** anomalies.
- Analyze functional dependencies to decompose tables from 1NF through BCNF.
- Articulate the trade-offs between normalized write-optimized OLTP schemas and denormalized read-optimized reporting models.
- Implement materialized views with refresh strategies to eliminate heavy runtime joins.
