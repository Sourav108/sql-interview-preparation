# Module 03: SELECT, Filter, and Sort

## Learning Objectives

By the end of this module, you will be able to:
- Explain the logical SQL query processing order from `FROM` to `LIMIT`.
- Distinguish logical processing order from physical execution order.
- Use every filtering predicate: `IN`, `BETWEEN`, `LIKE`, `ILIKE`, `IS NULL`, `IS NOT NULL`.
- Use `DISTINCT`, `ORDER BY` with `NULLS FIRST/LAST`, and `LIMIT`/`OFFSET`.
- Explain why `WHERE` cannot reference `SELECT` aliases.
- Write queries using the `R-E-Q-U-I-R-E` framework.
