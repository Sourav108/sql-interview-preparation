# Project 01: Production E-Commerce Database

A production-grade e-commerce relational schema supporting inventory management, multi-item order placement, and payment idempotency.

## Quickstart
```bash
psql -U postgres -d sql_interview_db < schema.sql
psql -U postgres -d sql_interview_db < seed.sql
psql -U postgres -d sql_interview_db < queries.sql
```
