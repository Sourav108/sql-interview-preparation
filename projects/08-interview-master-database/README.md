# Project 08: Comprehensive SQL Interview Master Database

The master relational database schema combining employees, departments, products, orders, payments, subscriptions, and telemetry for testing all 300+ interview problems.

## Quickstart
```bash
psql -U postgres -d sql_interview_db < schema.sql
psql -U postgres -d sql_interview_db < seed.sql
psql -U postgres -d sql_interview_db < queries.sql
```
